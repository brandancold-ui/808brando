# 808 Brando

Static GitHub Pages website for `808brando.com`.

## Beat licensing

- Public terms: `license/index.html`
- Reusable purchase certificate: `license/certificate-template.html`
- Future checkout record schema: `license/checkout-schema.json`
- Beat inventory and availability: `SITE_DATA.beats` in `script.js`

Each beat license action uses its verified `buyUrl` when one is supplied. Until then, it opens a prefilled email to `contact@808brando.com` with the beat, license, price, and current terms URL. Do not add a checkout URL until it has been verified.
